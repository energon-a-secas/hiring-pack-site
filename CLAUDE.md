# CLAUDE.md — Hiring Pack

Hiring Pack — interview kits and hiring resources for engineering managers (hiringpack.neorgon.com)

**Live:** hiringpack.neorgon.com · **Port:** 8843

## Run

```bash
make serve
```

Then open http://localhost:8843. It must be served over HTTP — the app is ES modules, and `file://` blocks them.

## Architecture

| Module | Lines | Owns |
|---|---:|---|
| `js/app.js` | 159 | — |

Vendored from `packages/neorgon-ui/` — never edit in place, run the sync script instead: `js/neorgon-footer.js`, `js/neorgon-header.js`.

## Data

No persisted state — everything lives in memory for the session.

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines. It currently holds.
- `js/app.js` is 159 lines against a 50-line guideline; it should be an entry point, not a module.
